## 🏆 最相关的开源项目

### 1. **Weddingly Builder** ⭐⭐⭐⭐⭐
**GitHub**: https://github.com/dannycahyo/weddingly-builder
**Stars**: 19 ⭐
**最后更新**: 2025年12月

#### **功能**:
- ✅ 单页婚礼网站构建器
- ✅ RSVP管理
- ✅ 照片画廊
- ✅ 背景音乐上传
- ✅ 密码保护
- ✅ Google Maps集成
- ✅ 礼物注册链接

#### **技术栈**:
```
Frontend: Astro 5.14 + React 19 + Tailwind CSS 4.1
Backend: Prisma 6.18 + PostgreSQL
Media: Cloudinary (图片/音频上传)
Animations: Framer Motion
Forms: React Hook Form + Zod
UI: Radix UI + Lucide Icons
```

#### **优点**:
- ✅ 现代技术栈
- ✅ 完整的RSVP系统
- ✅ 美观的UI/UX
- ✅ MIT许可证（可商用）

#### **缺点**:
- ❌ 没有AI功能
- ❌ 没有照片收集功能（只有画廊）
- ❌ 没有POD集成
- ❌ 没有设计生成器

#### **我们可以借鉴**:
- 📐 项目结构（Astro + React）
- 🎨 UI组件（Radix UI）
- 📸 Cloudinary集成
- 🔒 密码保护逻辑

## 💡 我们可以借鉴的技术

```typescript
// 项目结构
src/
├── components/
│   ├── guest/          // 客人页面组件
│   ├── sections/       // 构建器部分
│   └── ui/             // 可复用UI组件
├── pages/
│   ├── api/            // API端点
│   ├── builder.astro   // 管理员构建器
│   └── [slug].astro    // 动态婚礼页面
└── lib/
    ├── prisma.ts       // 数据库客户端
    └── validations.ts  // Zod验证
```

### **技术栈建议**:
```
Frontend: Next.js 15 (比Astro更灵活)
UI: React 19 + Tailwind CSS 4
Database: Prisma + PostgreSQL
Media: Cloudinary (图片/音频)
AI: OpenAI API / Replicate
Forms: React Hook Form + Zod
Animations: Framer Motion
UI Components: Radix UI / shadcn/ui
```
